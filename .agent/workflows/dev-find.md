# /dev-find — Find a Project

## Steps

// turbo
1. **Search by name or keyword**
   ```bash
   rafter find <query>
   ```

2. **If the user wants to see all deployment URLs**
   ```bash
   rafter deployments
   ```

3. **If the user wants to open the Mission Control dashboard**
   ```bash
   rafter dashboard
   ```

4. **If the user wants to see the full port map**
   ```bash
   rafter ports
   ```
